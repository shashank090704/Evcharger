# EvoCharge

EvoCharge is a modern Android application built with Kotlin that helps electric vehicle users discover nearby charging stations, view station details, book a slot, and complete payments smoothly.

This app connects with the backend repository: https://github.com/Aditya-gupta99/EvoCharge-Backend

Maintained by Your Name

## Features
- Find nearby charging stations on a map
- Browse station details in a list view
- Get suggestions for the closest available charging point
- Book and reserve a charging slot
- Make online payments securely
- Customize your profile
- Sign in and manage user authentication

## Project Status
This project is actively being improved to provide a better EV charging experience.

## Getting Started
1. Clone the repository
   ```sh
   git clone https://github.com/Aditya-gupta99/EvoCharge-App.git
   ```
2. Open the project in Android Studio.
3. Let Gradle sync and build the app.
4. Run it on an emulator or physical device.

## Development Setup
Make sure you have Android Studio and the required Android SDKs installed before building the project.
